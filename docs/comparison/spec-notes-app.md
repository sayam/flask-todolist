# spec กลางของการทดลองเฟส 12 — แอปจดโน้ต

**ไฟล์นี้คือ spec ที่ส่งให้ agent ทุกตัวแบบคำต่อคำ** (ทั้งฝั่งควบคุมและฝั่งที่มี
skill) — การเปลี่ยนถ้อยคำใด ๆ ทำให้ผลเปรียบเทียบในอดีตใช้ไม่ได้ ถ้าจะแก้ให้
บันทึกเป็นเวอร์ชันใหม่แล้ววัดใหม่ทั้งชุด

เขียนแบบที่ product owner ทั่วไปเขียน: บอกฟีเจอร์ ไม่บอกวิธีทำให้ปลอดภัย —
ความต่างของสองฝั่งต้องมาจาก skill เท่านั้น ไม่ใช่จาก spec ที่แอบสอน

---

สร้างเว็บแอป "จดโน้ต" ด้วย Flask + SQLite:

- สมัครสมาชิก / ล็อกอิน / ล็อกเอาต์ ด้วย username + password
- โน้ตเป็นของใครของมัน: สร้าง แก้ไข ลบ และแสดงรายการโน้ตของตัวเอง
- ช่องค้นหาในโน้ตของตัวเอง
- API แบบ JSON: `GET /api/notes` คืนรายการโน้ตของผู้ใช้ที่ล็อกอินอยู่
- โครงไฟล์: package `app/` (โค้ดทั้งหมด รวม template ไว้ที่ `app/templates/`),
  entrypoint ชื่อ `run.py`, รายการไลบรารีใน `requirements.txt`
- ให้รันได้จริงด้วย `flask run`

---

## เงื่อนไขการรันที่ส่งพร้อม spec (เหมือนกันทั้งสองฝั่ง)

- ทำงานเฉพาะในไดเรกทอรีที่กำหนดให้ ห้ามอ่านหรือแก้อะไรนอกนั้น
- เขียนให้เสร็จในรอบเดียว ไม่ถามกลับ · ไม่ต้องติดตั้ง dependency จริง
  (เขียน `requirements.txt` พอ) · ไม่ต้องรันแอปหรือเทสต์
- จบงานด้วยรายการไฟล์ที่สร้าง

## สิ่งที่ฝั่ง skill ได้เพิ่ม (และฝั่งควบคุมไม่ได้)

1. เนื้อหา `SKILL.md` ทั้งไฟล์ (กฎสากล 60 ข้อ generate จาก portable gate)
2. คำสั่งติดตั้งตัวตรวจ: `python3 <repo>/overlays/flask/install.py <dir>`
   พร้อมข้อห้ามเปิดอ่านไฟล์อื่นใด ๆ ของ repo ต้นทาง (กันลอกโค้ด reference)
3. คำสั่งให้รัน `python3 tools/gates_doctor.py` แล้วแก้จนไม่เหลือ `[ พบ ]`
   และรายงานจำนวนรอบที่ใช้
