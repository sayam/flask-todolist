## ทำไมมันย้าย

การทดลองนี้ตอบคำถามว่า **"scaffolding ที่ export ออกไป เปลี่ยนโค้ดที่ถูกเขียน
จริงไหม"** — ซึ่งเป็นคำถามเกี่ยวกับ `verifiable-gates` ไม่ใช่เกี่ยวกับ todolist ·
เมื่อกฎ เครื่องมือ และตัวบังคับย้ายไปที่นั่นครบแล้ว **หลักฐานของข้ออ้างควรอยู่
ที่เดียวกับข้ออ้าง** ไม่ใช่คนละ repo กัน · vg มี DOI ถาวรด้วย คนที่อ่านคำอ้าง
จึงตรวจสอบได้จากที่เดียว

## ข้อจำกัดที่ยังต้องอ่านคู่กับตัวเลขเสมอ

ไม่ได้หายไปเพราะย้าย — ทั้งสามข้ออยู่ในรายงานฉบับ vg ครบ:

1. แขน skill ได้รอบตรวจเพิ่ม (ปิดด้วยแขนที่สาม)
2. 10 ข้อของ probe ถูกเลือกโดยคนเดียวกับที่เขียนกฎ — **อิสระจาก "ด่านที่ agent
   เห็น" ไม่ใช่อิสระจาก "สิ่งที่ถูกสอน"**
3. N=5 ต่อแขน ไม่มีการปฏิบัติทางสถิติใด ๆ — สิ่งที่ยืนยันได้คือรูปแบบที่ซ้ำ
   ไม่ใช่ระยะห่างของค่าเฉลี่ย
