# Compliance รายประเทศ — ดัชนีของชั้น legal

G4 ของแผน governance ([ROADMAP-GOVERNANCE.md](ROADMAP-GOVERNANCE.md) ·
[ADR 0051](adr/0051-project-constitution-and-intake.md)) — ธรรมนูญให้
"กฎหมายรายประเทศ" เป็นแกนหนึ่งของชั้น security โดยประเทศแรกที่ craft คือไทย
· ไฟล์นี้คือดัชนีและ**สัญญาของการเพิ่มประเทศถัดไป**: เพิ่มแบบ additive
เท่านั้น ไม่แตะของเดิม ไม่ย้ายไฟล์ (ลิงก์เก่าห้ามตาย)

## ประเทศที่ประเมินแล้ว

| ประเทศ | กฎหมาย | worksheet | ด่าน |
|---|---|---|---|
| ไทย | PDPA (พ.ร.บ. คุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562) | `docs/PDPA.md` | `gate legal-pdpa-worksheet-honest` |

การผูกกับความจริง: gate ของชั้น legal ใช้ id ขึ้นต้น `legal-` เป็น
convention — `tests/test_compliance_index.py` บังคับสองทิศ: ทุก gate
`legal-*` ต้องมีแถวในตารางนี้ และทุกแถวต้องชี้ gate `legal-*` ที่มีจริง
พร้อม worksheet ที่มีจริง — ประเทศใหม่ที่มีด่านแต่ไม่ลงดัชนี = แดง

## นิยามขั้นต่ำของ "ประเมินแล้วหนึ่งประเทศ"

ตามบรรทัดฐานที่ PDPA ตั้งไว้ (อย่างต่ำต้องเท่านี้ ทุกข้อ):

1. **worksheet ต่อข้อบังคับ** — สถานะ `ผ่าน`/`ไม่เกี่ยวข้อง`/`ยังไม่ผ่าน`
   พร้อมหลักฐานใน backtick ที่เทสต์ resolve ทุกชิ้น · ไม่มี "ยังไม่ประเมิน"
2. **ขอบเขตประกาศชัด** — ไม่ใช่คำปรึกษากฎหมาย · "ผ่าน" = ซอฟต์แวร์มีกลไก
   หน้าที่ตามกฎหมายเป็นของผู้ deploy ในประเทศนั้น
3. **ชั้น legal ไม่ break พื้นฐาน** (ADR 0042) — ทุกแถวอ้างกลไกที่มีอยู่
   ช่องว่างเข้า backlog ไม่ใช่ไปหักด่านเดิม (หลักเดียวกับ intake ของ
   ADR 0051: baseline ห้าม break)
4. **gate ลงทะเบียนใน `gates.yaml`** ด้วย id `legal-<ชื่อ>` ·
   `layer: business` (ข้อตกลงของแอปที่ให้บริการผู้ใช้ในประเทศนั้น —
   ADR 0057 ยก pilot ของ PDPA ขึ้นชั้นนี้แล้ว) · `pillar: security`
   แล้วมาลงแถวในดัชนีนี้

## สิ่งที่ตั้งใจไม่ทำ

- **ไม่ประเมินประเทศที่ไม่มีใคร deploy จริง** — worksheet ที่ไม่มีผู้ใช้
  คือเอกสารที่เน่าโดยไม่มีใครเดือดร้อน ประเทศใหม่เพิ่มเมื่อมีความต้องการจริง
  (หลัก intake: "ดีเฉพาะบางสถานการณ์ = รับแบบจำกัดขอบเขต")
- **ไม่ทำ abstraction ข้ามกฎหมาย** — แต่ละประเทศได้ worksheet ของตัวเอง
  เต็มใบ ไม่พยายามสร้าง "กฎหมายกลาง" ที่ map ทุกประเทศ (เหตุผลเดียวกับที่
  ไม่ทำ abstraction ข้าม framework — ADR 0040)
