# PDPA (พ.ร.บ. คุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562) — worksheet ของซอฟต์แวร์

pilot ของ **ชั้น legal** ตามเฟส 13-04 ([ROADMAP-FEATURES.md](ROADMAP-FEATURES.md))
— รูปแบบเดียวกับ [ASVS.md](ASVS.md): สถานะต่อข้อ + หลักฐานใน backtick ที่
`tests/test_pdpa.py` ตรวจว่ามีอยู่จริงทุกชิ้น

**ขอบเขตที่ต้องอ่านก่อนใช้ — สามข้อ:**

1. **ไม่ใช่คำปรึกษากฎหมาย** — เป็นการ map ข้อบังคับหลักของ พ.ร.บ. เข้ากับ
   กลไกที่ซอฟต์แวร์มี เพื่อให้ผู้ deploy ตอบคำถามของตัวเองได้เร็วขึ้น
2. **"ผ่าน" แปลว่าซอฟต์แวร์มีกลไกรองรับ** ไม่ได้แปลว่าผู้ deploy ปฏิบัติตาม
   กฎหมายแล้ว — หน้าที่ตามกฎหมายเป็นของ*ผู้ควบคุมข้อมูล* (คนที่รันระบบ)
   ซอฟต์แวร์เป็นได้แค่เครื่องมือ
3. **ชั้น legal ไม่ break พื้นฐาน** (ADR 0042) — ทุกแถวอ้างกลไกที่มีอยู่
   ไม่มีข้อไหนนิยามพฤติกรรมใหม่ · ช่องว่างไปอยู่ backlog ไม่ใช่ไปหักด่านเดิม

สถานะ: `ผ่าน` (มีกลไก + หลักฐาน) · `ไม่เกี่ยวข้อง` (พร้อมเหตุผล) ·
`ยังไม่ผ่าน` (ต้องอยู่ใน backlog ท้ายไฟล์)
