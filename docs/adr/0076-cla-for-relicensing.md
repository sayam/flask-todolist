# 0076 — ขอ CLA ที่ให้สิทธิ์ relicense จากผู้ร่วมพัฒนาภายนอก

สถานะ: **accepted** (2026-08-25) — เจ้าของตัดสินหลังอ่านบทวิเคราะห์คณะที่ปรึกษา
2026-08-24 · **แทนที่ [ADR 0070](0070-relicense-to-agpl-and-cc-by-sa.md) เฉพาะข้อ 4**
(ส่วน "ไม่มี CLA — ผู้ร่วมพัฒนาคนที่สองทำให้สัญญาอนุญาตถาวร") และ **แทนที่
[ADR 0073](0073-dco-sign-off.md) เฉพาะข้อ 1** ตรงประโยค "ใช้ DCO *ไม่ใช่* CLA" — DCO
ยังบังคับทุก commit เหมือนเดิม ใบนี้*เพิ่ม* CLA ไม่ได้ถอด DCO

## บริบท

ADR 0070 เลือก AGPL โดยมีเงื่อนไขข้อ 4 ว่า "เจ้าของถือลิขสิทธิ์คนเดียวจริง จึงขาย
ข้อยกเว้นเชิงพาณิชย์ได้เมื่อไหร่ก็ได้" และ `CONTRIBUTING.md` เขียนต่อว่า
**พอมีผู้ร่วมพัฒนาประจำคนที่สอง สัญญาอนุญาตจะเปลี่ยนอีกไม่ได้โดยง่าย — นี่เป็นการ
แลกที่ตั้งใจ** · ADR 0073 เลือก DCO แทน CLA ด้วยเหตุผลว่าโปรเจกต์คนเดียวไม่มี
กำลังดูแลทะเบียนผู้ลงนาม

สองข้อเท็จจริงเปลี่ยนไปตั้งแต่นั้น:

1. **โปรเจกต์กลายเป็นวิทยานิพนธ์และมีเจตนาระยะยาวที่ประกาศแล้ว** (ADR 0075):
   นำไปใช้ในมหาวิทยาลัยไทย/ราชการ และ*เผื่อ*ทางเชิงพาณิชย์ · ทางนั้นต้องการ
   dual-license ซึ่งต้องการลิขสิทธิ์ที่รวมศูนย์ — คำว่า "แลกที่ตั้งใจ" ใน 0070 ถูก
   ตัดสินตอนที่ยังไม่มีเจตนานี้
2. **มีผู้ร่วมพัฒนาภายนอกคนแรกแล้ว** — PR #225 แตะ 40+ ไฟล์ (scripts · tests ·
   plugins) · วันที่ merge โดยไม่มี CLA คือวันที่ dual-license ของไฟล์เหล่านั้นต้อง
   ขอความยินยอมย้อนหลัง ซึ่งคณะที่ปรึกษาระบุว่าเป็น "ทางพาณิชย์ที่ปิดโดยไม่รู้ตัว"

ต้นทุนที่ 0073 กลัว (ทะเบียนผู้ลงนาม) ยังจริง แต่เล็กกว่าที่คิด: ลายเซ็นอยู่ใน
คำอธิบาย PR ซึ่ง GitHub เก็บถาวรและค้นได้ — ไม่ต้องมีทะเบียนแยก

## คำตัดสิน

1. **ผู้ร่วมพัฒนาภายนอกต้องยอมรับ `CLA.md` ก่อน merge — เฉพาะ PR ที่แตะ path ของ
   core** (`scripts/` · `overlays/` · `skill/` · `gates.yaml` · `docs/comparison/`
   · เทสต์ของพวกนั้น) ซึ่งกำลังจะถูกถอดไปเป็น repo `verifiable-gates` ภายใต้
   Apache-2.0 (ADR 0075 ข้อ 6) · **โค้ดของตัวแอป (`app/` · `migrations/` · เทสต์
   ของแอป) ไม่มี CLA** — คำสัญญาของ ADR 0070 ยังจริงสำหรับส่วนนั้น · ลงนามด้วย
   บรรทัดเดียวในคำอธิบาย PR · ใบนี้ให้สิทธิ์*ใช้และ relicense* (รวมถึงเผยแพร่ใน
   verifiable-gates ภายใต้ Apache-2.0) ไม่โอนลิขสิทธิ์ ผู้เขียนยังถือของตัวเอง
   (รูปเดียวกับ Apache ICLA — ไม่ใช่ copyright assignment)
2. **ผู้ดูแลผูกพันกลับ**: ทุกรุ่นที่มีงานของผู้ร่วมพัฒนาจะยังเผยแพร่ภายใต้สัญญาที่
   OSI รับรอง — CLA นี้เปิดทาง*ควบคู่* ไม่ใช่ทาง*ปิด*
3. **DCO ยังบังคับทุก commit** (ADR 0073 ข้อ 2–3 ไม่เปลี่ยน) — DCO รับรองความเป็น
   ผู้เขียน CLA ให้สิทธิ์ คนละหน้าที่
4. **PR ที่เปิดอยู่ก่อนใบนี้ (#225) ขอลงนามก่อน merge** — เพราะมันแตะ `scripts/`
   และ `overlays/` 20 ไฟล์ ซึ่งอยู่ในขอบเขตข้อ 1 ทั้งหมด — ถ้าผู้เขียนไม่ประสงค์
   ลงนาม ผู้ดูแลจะไม่ merge และจะไม่เขียนของเดียวกันซ้ำเพื่อเลี่ยง (เป็นการเอา
   งานเขาโดยไม่ให้เครดิต) — ปิด PR อย่างสุภาพและปล่อย issue #186 ให้คนถัดไป
5. **ทะเบียนผู้ลงนามคือ GitHub เอง**: คำอธิบาย PR ที่ merge แล้ว · ไม่สร้างไฟล์
   ทะเบียนที่สอง (ADR 0072 — ทะเบียนที่ไม่มีใครเทียบกับของจริง)

## ทางเลือกที่ไม่ได้เลือก

| ตัวเลือก | ทำไมไม่เลือก |
|---|---|
| **ไม่มี CLA — AGPL ถาวร** | เป็นมิตรกับ OSS ที่สุด และทางพาณิชย์แบบ*บริการ*ยังเปิด · แต่ปิดทาง dual-license ถาวรตั้งแต่ PR แรก ทั้งที่เจตนาระยะยาวเพิ่งถูกประกาศ — ปิดทางที่ยังไม่ได้ตัดสินใจ คือการตัดสินใจโดยไม่รู้ตัว |
| **copyright assignment (โอนลิขสิทธิ์)** | ให้อำนาจมากกว่าที่ต้องการ และผู้ร่วมพัฒนาส่วนใหญ่ปฏิเสธ · สิทธิ์ relicense พอแล้ว |
| **เลื่อน — hold PR #225 ไว้** | ซื้อเวลาแต่เสียผู้ร่วมพัฒนาคนแรก และคำถามไม่ได้ง่ายขึ้นเมื่อรอ |
| **CLA ทั้ง repo** (ร่างแรกของใบนี้) | กลับคำสัญญาของ ADR 0070 ทั้งหมดโดยไม่จำเป็น — ส่วนที่ต้องการสิทธิ์ relicense คือ core ที่จะถอด ไม่ใช่ตัวแอป · ขอบเขตตาม path ให้สิ่งที่ต้องการพอดีและรักษาคำสัญญาเดิมกับคนที่แก้ตัวแอป |
| **CLA ผ่านบริการภายนอก (CLA assistant ฯลฯ)** | เพิ่มผู้ให้บริการอีกรายในทะเบียน SUPPLY-CHAIN โดยที่บรรทัดเดียวใน PR ทำงานเดียวกัน |

## สิ่งที่ใบนี้ไม่ตอบ และรู้ตัว

- **โค้ดที่ AI สร้าง ใครเป็นเจ้าของลิขสิทธิ์ตามกฎหมายไทย** — ยังไม่ชัด · CLA ให้
  ผู้ส่ง*รับผิดชอบ*ส่วนที่ AI สร้าง แต่ไม่ได้ตอบว่าใครเป็นเจ้าของ · ต้องปรึกษา
  นักกฎหมายก่อนวันที่ dual-license เกิดจริง — ใบนี้ไม่ใช่คำแนะนำทางกฎหมาย
- **ผลต่อจำนวนผู้ร่วมพัฒนา** — CLA ลด PR จากคนนอกในหลายโปรเจกต์ · วัดได้: ถ้า
  6 เดือนหลังใบนี้ไม่มี PR ภายนอกที่ลงนามเลย ให้ทบทวน

## เงื่อนไขที่ทำให้คำตัดสินหมดอายุ

- วันที่ตัดสินว่า**ไม่**ไปทางพาณิชย์แน่นอน → ถอน CLA ได้ (กลับไปรูปของ 0070)
- วันที่มีนิติบุคคล (บริษัท/มูลนิธิ) ถือลิขสิทธิ์แทนบุคคล → ต้องออก CLA v2 ที่
  คู่สัญญาเป็นนิติบุคคลนั้น และผู้ลงนามเดิมต้องลงใหม่
