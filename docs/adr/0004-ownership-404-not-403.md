# 0004 — ข้อมูลของคนอื่นตอบ 404 ไม่ใช่ 403

สถานะ: accepted (backfill — ตัดสินใจจริงช่วง feature auth)

**บริบท:** ทุก resource มีเจ้าของ การตอบ 403 บอกผู้โจมตีว่า id นั้นมีอยู่จริง
**คำตัดสิน:** helper `_owned_*()` ตอบ 404 เสมอเมื่อไม่ใช่ของตน — enumeration
ไม่ได้ข้อมูลอะไรกลับไป ห้ามใช้ `db.get_or_404()` กับข้อมูลมีเจ้าของ
**ผล:** เทสต์ ownership ทุกตัว assert 404 / ผู้ใช้ที่พิมพ์ id ผิดก็เห็น 404
เหมือนกัน (ยอมรับได้ — ไม่มี use case แชร์ข้าม user)
