# 0007 — โหมด auto ใช้ตารางดวงอาทิตย์ฝังในแอป

สถานะ: accepted (backfill — ตัดสินใจจริงช่วง mode auto)

**บริบท:** โหมด auto สลับสว่าง/มืดตามดวงอาทิตย์ขึ้น-ตกของ timezone ผู้ใช้
**ทางเลือก:** (ก) เรียก sunrise API (ข) คำนวณสดทุก request (ค) ตาราง
รายเดือน generate ล่วงหน้า commit ลง repo
**คำตัดสิน:** (ค) — ไม่มี network dependency, ไม่มี latency, reproducible
พิกัดจาก zone.tab ของ tzdata คำนวณด้วยสูตรดาราศาสตร์ในสคริปต์เอง
**ผล:** คลาดเคลื่อน ≤ ~10 นาที (พอสำหรับเลือกสี) / ต้องครอบทุกชื่อใน
`available_timezones()` — เคยหลุด 286 โซนมาแล้ว มีเทสต์เทียบสองชุดกันถาวร
