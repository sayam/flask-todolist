# advisory ของไลบรารีที่ **plugin** ประกาศไว้ ซึ่งประเมินแล้วว่ารับไว้
#
# แยกจาก `pins/accepted-advisories.txt` (เครื่องมือของ CI) และ
# `deploy/accepted-image-advisories.txt` (OS layer ของ image) เพราะสามชั้นนี้
# มีทางออกคนละแบบ — ของชั้นนี้ **ถอดได้ทันทีด้วย `DISABLED_PLUGINS`** โดยไม่ต้อง
# deploy ซึ่งเป็นคำตอบที่ ADR 0025 บอกว่าเร็วที่สุด
#
# `scripts/audit_plugin_deps.py` อ่านไฟล์นี้แล้วบังคับสองทิศ:
#   - เจอ advisory ที่ไม่ได้อยู่ในไฟล์นี้ → **แดง** (ต้องมีคนตัดสิน)
#   - ID ในไฟล์นี้ที่ไม่โผล่ในผลอีกแล้ว → **แดงเหมือนกัน**
#
# **เหตุผลของแต่ละข้ออยู่ใน `docs/SECURITY-CADENCE.md`** หัวข้อ
# "ช่องโหว่ในไลบรารีของ plugin" พร้อมเงื่อนไขที่ทำให้คำตัดสินหมดอายุ
#
# ปกติไฟล์นี้ควรว่าง — ทางออกที่เร็วที่สุดของ CVE ในของที่ถอดได้ คือถอดมัน
